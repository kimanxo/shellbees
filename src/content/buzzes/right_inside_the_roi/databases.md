This technical briefing introduces database fundamentals, relational and non-relational models, SQL, database design, indexing, transactions, performance, security, distributed databases, and modern data infrastructure.

## Key Concepts

- **Database:** An organized collection of data that can be efficiently stored, accessed, and managed.

- **DBMS (Database Management System):** Software that provides the tools and mechanisms required to create, manage, query, and secure databases.

- **Relational Database:** A database that organizes data into related tables and typically uses SQL for querying and manipulation.

- **SQL (Structured Query Language):** A language used to interact with relational databases.

- **Primary Key:** A column or combination of columns that uniquely identifies a record in a table.

- **Foreign Key:** A field that references a key in another table to establish a relationship between records.

- **Index:** A data structure that allows the database to locate records more efficiently without scanning an entire table.

- **Normalization:** The process of organizing relational data to reduce redundancy and improve consistency.

- **Transaction:** A sequence of database operations treated as a single logical unit of work.

- **ACID:** Four properties—Atomicity, Consistency, Isolation, and Durability—that provide reliable transaction processing.

- **NoSQL:** A category of database systems designed around data models other than the traditional relational model.

- **Replication:** Maintaining copies of data across multiple database servers to improve availability and reliability.

- **Sharding:** Splitting data across multiple database servers to distribute storage and workload.

- **CAP Theorem:** A principle describing the trade-offs between consistency, availability, and partition tolerance in distributed systems.
